"Apple" in the uploader column means Apple's own channel. Everything else is an upload by someone else, so it may be taken down or moved.

## Using them

These recordings are copyrighted. To embed them, use YouTube's own player with `start` and `end` set, for example `https://www.youtube.com/embed/MnrJzXM7a6o?start=132&end=178`, and keep the player visible, which YouTube's terms require. That works on a normal web page, but not inside a claude.ai artifact, which blocks embedded sites.

To use a clip as a sound file instead, you need the rights to it. Then put the file in `audio/custom/` and list it in `CUSTOM` at the top of `js/sound.js`.
